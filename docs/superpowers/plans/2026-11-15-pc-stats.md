# PC Stats Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Jarvis-styled, fully editable PC stats dashboard on a chosen side monitor (native WPF), the same dashboards live on web and iPhone (Agents card → View stats), stats history on the server, and WattSeal-style whole-PC watts — as the `pc-stats` Power integration.

**Architecture:** A LocalSystem helper service on the PC (`JarvisSensors`, LibreHardwareMonitorLib on PawnIO + ETW present events) streams raw readings over an ACL'd pipe to the Jarvis Windows app, which adds the power model, sessions and marked moments, draws the dashboard window, and uploads samples over HTTPS to the server (`/api/pc-stats`). The server stores rolled-up history, dashboards and the reading catalog in SQLite, serves live/history to web and iPhone, and exposes Jarvis tools; everything is gated by the `pc-stats` Power integration.

**Tech Stack:** Python (webui routes, SQLite, jarvis_power), C#/.NET 8 WPF + LibreHardwareMonitorLib + Microsoft.Diagnostics.Tracing.TraceEvent, vanilla JS (webui/static), SwiftUI (ios_app).

**Spec:** `docs/superpowers/specs/2026-11-15-pc-stats-design.md`

## Global Constraints

- Gaming rules: no surface over a fullscreen game, no focus stealing, no FPS cost (collector + window ≲ 1% of one core); look B drawn with cached static effects, data redraw ≤ 1 Hz, no drawing while minimised/covered.
- No DLL injection, no global hooks; the only kernel component is PawnIO (installed by default, switchable off in settings); never WinRing0.
- Read-only hardware access.
- Estimated values always carry an "estimated" marker; whole-PC watts are labelled "PC (est.)".
- WattSeal is GPL-3.0: reimplement its formulas, never copy code.
- Power integration rules: off stops every process (no collection, upload, storage, drawing); new tools live in toolset `pc_stats`; one switch.
- Retention: 10 s points 7 days, 1 min points 90 days, 1 h points forever; sessions and moments forever.
- Problems are only marked in history — no notifications.
- Each device remembers its own active dashboard; auto-switch applies to the PC window only.
- Dependencies pinned `[floor, next_major)` in `windows_app/Directory.Packages.props`.
- Ship: server deploy as usual; Windows via `windows_app/scripts/package.ps1` + install; iPhone via `ios_app/scripts/release.sh`.

## Review Focus

1. The PC is offline/asleep or never reported: card and page show "PC offline · last seen …" with the last history, never an endless spinner. (Task 2 `test_live_offline_returns_last_seen`.)
2. A reading this PC can't provide: widgets show "unavailable" with the reason, never 0. (Task 1 catalog test; Task 7 `Widget_UnavailableReading_ShowsReason`.)
3. A dashboard edited on two devices at once: stale `rev` refused (409 with the current copy), client reloads. (Task 1 `test_put_stale_rev_conflicts`.)
4. Jarvis writes a broken widget (unknown kind/reading, overlap, off-grid): refused with reasons, stored dashboard untouched. (Task 3 `test_tool_rejects_invalid_widget`.)
5. Integration switched off mid-session: uploads stop at once, window closes, routes 409, card numbers hide. (Task 2 `test_routes_409_when_off`; Task 6 `Collector_StopsWhenIntegrationOff`.)

### Task 1: Server catalog, store and dashboard model

**Files:** Create `webui/api/pc_stats_catalog.py`, `webui/api/pc_stats_store.py`; Test `webui/tests/test_pc_stats_store.py`.

**Interfaces — Produces:**
- `READINGS: dict[str, dict]` key → `{"label","unit","group","estimated": bool}`; fixed keys `cpu.load cpu.temp cpu.clock cpu.power gpu.load gpu.temp gpu.hotspot gpu.clock gpu.mem_clock gpu.power gpu.fan gpu.vram_used gpu.vram_total fps fps.low1 frametime ram.used ram.total ram.commit disk.used disk.read disk.write net.down net.up power.cpu power.gpu power.ram power.disk power.net power.total`; dynamic `^(fan|temp)\.[a-z0-9_]{1,40}$`. `reading_info(key) -> dict|None` resolves both.
- `WIDGET_KINDS = ("hero","number","chart","bars","ring","sparkline","text","session","moments")`, `GRID_COLUMNS = 12`.
- `validate_dashboard(d) -> list[str]`: id/name strings; ≤ 64 widgets; widget `id`, `kind ∈ WIDGET_KINDS`, `x,y ≥ 0`, `w,h ≥ 1`, `x+w ≤ 12`, no overlaps; `readings` all resolvable; `style` keys ⊆ `{chart,color,warn,crit,window,decimals,meta,label,unit}`, `chart ∈ {area,line,none}`, `color` `#RRGGBB`, `window` 60–86400, `meta` resolvable; `auto ∈ {None,"game"}`.
- `default_dashboards()`: "Overview" (look B: GPU hero 6×4 at 0,0; CPU hero 3×4; Frames hero 3×4; Power bars 4×4; Memory bars 4×4; Cooling bars 4×4), "Gaming" (`auto:"game"`), "Power".
- `PcStatsStore(root: Path, clock=time.time)`: `ingest(device_id, samples, estimated) -> int` (sample `{"t","r":{k:v},"game"}`; 10 s buckets avg/min/max, rolled to 1 min and 1 h; unknown keys dropped); `latest(device_id) -> {"t","r","game","estimated"}|None`; `history(device_id, key, t0, t1, points=300) -> [[t,avg,min,max]]` from the finest table covering the range; `add_sessions`/`sessions(device_id, limit=50)` (session `{"id","exe","title","start","end","fps_avg","fps_low1","cpu_temp_max","gpu_temp_max","energy_wh","watts_avg","watts_max","throttle_s"}`, upsert by id, newest first); `add_moments`/`moments(device_id, t0, t1)` (moment `{"id","t","key","value","threshold","kind","duration_s","label"}`); `energy(device_id, period, price, now) -> [{"start","kwh","cost"}]` integrating `power.total`; `prune(now)`; `dashboards()` (seeds defaults once), `dashboard(id)`, `put_dashboard(d, rev) -> d` (`Conflict` on stale rev, `ValueError(errors)` on invalid, stores `rev+1`), `delete_dashboard(id)`. DB `get_hermes_home()/"pc_stats"/"pc_stats.db"`; `store()` singleton.

### Task 2: `pc-stats` Power integration + routes

**Files:** Create `jarvis_power/integrations/pc_stats/{__init__.py,ui.json}`, `webui/api/pc_stats_routes.py`; Modify `webui/api/mounts.py` (`("/api/pc-stats","api.pc_stats_routes")`), `jarvis_power/surfaces.py` (`ios.pc_stats`, `web.pc_stats`, `windows.pc_stats`); Tests `tests/jarvis_power/integrations/test_pc_stats.py`, `webui/tests/test_pc_stats_routes.py`.

**Interfaces — Produces (JSON):**
- `POST /api/pc-stats/samples` `{"device_id","samples","estimated","sessions","moments"}` → `{"ok":true,"live":bool}` (`live` = a viewer polled `/live` for that device in the last 15 s).
- `GET /api/pc-stats/live?device_id=` → `{"online","at","sample","estimated","name"}` (`online` = sample < 30 s old); marks watched. `device_id` optional: defaults to the most recent reporting device.
- `GET /api/pc-stats/summary?device_id=` → `{"online","at","cpu","gpu","hottest","watts"}`.
- `GET /api/pc-stats/history?device_id=&key=&from=&to=&points=` → `{"points"}`; `GET …/sessions?limit=` → `{"sessions"}`; `GET …/moments?from=&to=` → `{"moments"}`; `GET …/energy?period=day|week|month` → `{"buckets","price","currency"}`.
- `GET /api/pc-stats/catalog` → `{"readings","widget_kinds","columns":12}`.
- `GET /api/pc-stats/dashboards` → `{"dashboards"}`; `PUT /api/pc-stats/dashboards/<id>` `{"dashboard","rev"}` → `{"dashboard"}` | 409 `{"error":"changed elsewhere","dashboard":current}` | 400 `{"errors"}`; `DELETE /api/pc-stats/dashboards/<id>`.
- `GET /api/pc-stats/settings` → the integration's setting values.
- Integration `id="pc-stats"`, `name="PC Stats"`, `icon="gauge.with.dots.needle.67percent"`, summary "A live dashboard of your PC on a side monitor, your phone and the web, with history and watts.", `processes=("webui",)` (hourly prune thread), `toolsets=("pc_stats",)`, `route_prefixes=("/api/pc-stats",)`, surfaces as above. Settings: `monitor` text "", `open_at_login` toggle True, `price` number 0.15, `currency` text "USD", `psu_efficiency` number 90 (50–100 %), `history` toggle True, `interval` number 1 (1–10 s), `cpu_tdp` number 0, `gpu_tdp` number 0, `sensor_driver` toggle True (help: kernel driver, some anti-cheat may flag it), `warn_gpu_temp` 85, `warn_cpu_temp` 95, `warn_power_spike` 1.3, `warn_fps_drop` 40.
- [ ] Tests: discovery validation; `test_routes_409_when_off`; `test_samples_then_live_and_summary`; `test_live_offline_returns_last_seen`; `test_live_flag_true_only_while_watched`; `test_dashboards_put_conflict_and_400`. Implement; green; commit.
